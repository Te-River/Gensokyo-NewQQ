# [CQ:location]

## 用途

`[CQ:location]` 用于发送位置信息，包含经纬度、地名和样式信息。

范围：`-`（QQ Bot API 暂不支持发送）

## 语法

```text
[CQ:location,lat=39.908823,lon=116.397470,title=北京市,content=天安门广场,style=1]
```

## 参数

| 参数名 | 必填 | 说明 |
|--------|------|------|
| `lat` | ✅ | 纬度 |
| `lon` | ✅ | 经度 |
| `title` | ❌ | 地名/标题 |
| `content` | ❌ | 详细地址描述 |
| `style` | ❌ | 样式（具体值取决于客户端实现） |

## 与标准 OneBot V11 的差异

QQ Bot API（官方 API）**不提供**发送位置信息的接口。`[CQ:location]` 在 Gensokyo 中**无法发送**。

| 差异点 | 标准 OneBot V11 | Gensokyo 实现 |
|--------|----------------|---------------|
| 发送位置 | ✅ 支持 | ❌ QQ Bot API 不支持 |
| 入站上报 | ✅ 收到位置时上报 | ❌ QQ Bot 不推送位置消息 |

## 发送行为

不支持。如果消息中包含 `[CQ:location]`，该 CQ 码会被忽略或作为文本原样发出。

## 替代方案

如需分享位置，可以将地名和坐标作为文本发送：

```python
await bot.send_group_msg(
    group_id=123456,
    message="位置：北京市天安门广场 (39.908823, 116.397470)",
)
```

## 注意

- QQ Bot API 与 go-cqhttp 等第三方实现不同，不支持位置消息功能。
- 如需地图相关功能，可考虑发送地图截图（使用 `[CQ:image]`）作为替代。
